# UI Tests for «Яндекс.Самокат» - JUnit 5 + Selenium

Яндекс Практикума "Автоматизатор тестирования на Java".
Финальный проект 6ого спринта по UI тестированию сервиса [«Яндекс.Самокат»](https://qa-scooter.education-services.ru/) с использованием JUnit 5, Selenium.

---

## ✅ Что покрыто

- Выпадающий список в разделе «Вопросы о важном». Когда нажимаешь на стрелочку, открывается соответствующий текст.
- Заказ самоката. Весь флоу позитивного сценария с двумя наборами данных.
- Если нажать на логотип «Самоката», попадёшь на главную страницу «Самоката».
- Если нажать на логотип Яндекса, в новом окне откроется главная страница Яндекса.
- Сообщения об ошибке заполнения для всех полей формы заказа, которые проверяют значения.
- Если ввести неправильный номер заказа, открывается страница статуса заказа и на ней написано, что такого заказа нет.
